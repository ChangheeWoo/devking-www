06 / BEFORE WE START

시작하기 전에 궁금한 것들.

무엇을 자동화할지 아직 명확하지 않아도 괜찮나요?

현재 업무 순서와 반복해서 만드는 파일, 사용하는 도구를 알려주세요. 시간이 많이 드는 지점을 함께 살펴보고 우선 검토할 과제를 정할 수 있습니다.

기존에 사용하는 엑셀이나 시스템을 바꿔야 하나요?

현재 도구를 활용하거나 연결하는 방법부터 검토합니다. 연동 가능 여부는 API 제공 여부, 접근 권한, 파일 형식 등 실제 환경을 확인해야 합니다.

AI가 처리한 결과는 어떻게 확인하나요?

업무의 중요도에 따라 담당자 검토와 승인 단계를 설계합니다. 시범 적용 과정에서 오류 유형과 확인 기준을 정하고, 예외 상황을 처리할 방법을 함께 검토합니다.

기간과 비용은 어떻게 정하나요?

대상 업무, 자료의 형태와 분량, 연동 대상, 검수 기준을 확인한 후 범위와 견적을 제안합니다. 작은 범위의 시범 적용부터 시작하는 방식도 협의할 수 있습니다.
